Legal & Infrastructure

Security

Last updated: September 2026

Here's how Hyde protects your account and your conversations — in plain language, not legal boilerplate.

Your password is never stored in readable form. All traffic between your device and Hyde is encrypted in transit.

How your data is protected

Encryption in transit

Every connection to Hyde uses HTTPS, so data moving between your device and our servers is encrypted.

Hashed passwords

We never store your password in plain text — only a one-way hashed version that cannot be reversed.

Zero ad trackers

Hyde does not run advertising trackers or third-party analytics scripts that profile you.

Keeping your own account secure

  • Use a strong, unique password — not one you've reused on another site.
  • Log out of Hyde on shared or public devices.

Found a security issue?

We take vulnerability reports seriously.
If you've found an issue, please email security@hydethinks.com.

def is_prime(n):
    if n < 2:
        return False
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            return False
    return True
